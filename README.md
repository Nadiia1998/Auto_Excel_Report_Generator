
# 📊 Auto Excel Report Generator


A Python tool that analyzes e-commerce data from a CSV file and automatically creates a professional Excel report with KPIs, charts, and pivot tables.

---

## 🚀 Features
- Generate monthly reports (enter month number 1–12)  
- Calculate KPIs: total revenue, average order value, total quantity, total orders  
- Create tables by product category and country  
- Add bar and line charts directly in Excel  
- Save report automatically in the same folder as the script or `.exe`

---


## ⚙️ Usage
1. Place your `ecommerce` file in the same folder as the script or `.exe`.  
2. Run the script:
   ```bash
    python auto_excel_report_genrator.exe```
